Backend engineer building AI agent systems — APIs, automation, and LLM-powered tooling.

## Currently building
- Multi-agent orchestration and monitoring: a dashboard that tracks agent loops, daemons, and cron jobs across services, with a staleness-detection model blending heartbeats and commit activity, and an LLM reasoning layer that proposes next-step instructions for human approval before anything is delivered.
- LLM-powered operational agent: a Claude-based agent with a file-based memory architecture (charter, playbook, ledger) so it can operate across ongoing engagements with an auditable, inspectable history.
- Backend services for e-commerce and content platforms: headless CMS and API backends (Node.js/Strapi) powering storefronts and admin workflows.
